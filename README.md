# TypeScript Problem Solving 

This repository contains solutions to 10 programming problems completed using TypeScript. The problems focus on practicing core programming concepts such as arrays, strings, objects, loops, conditionals, sets, and basic problem-solving techniques.

## Topics Covered

- Array and string manipulation
- Object transformation
- Loops and conditionals
- Sets and duplicate handling
- Sorting and filtering
- Date objects
- Nested objects and optional chaining
- Pagination logic
- Queue simulation
- TypeScript interfaces and types

## Technologies Used

- TypeScript
- JavaScript ES6 concepts

## Purpose

The purpose of this assignment is to strengthen problem-solving skills and practice writing clean and logical TypeScript solutions while handling different edge cases.
